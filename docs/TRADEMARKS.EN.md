# Trademark and Attribution Policy

[README](./README.EN.md) · [Contributing](./CONTRIBUTING.EN.md) · [简体中文](./TRADEMARKS.md)

`AI-Tidu9` and `九门赛博提督` identify this open-source project and its original distribution. The policy has one purpose: **enable truthful use of the project without making modified products appear officially endorsed.**

## ✅ Permitted use

| Context | Acceptable wording |
| --- | --- |
| Compatibility | “Compatible with AI-Tidu9 Capability Provider Protocol” |
| Origin | “Built on AI-Tidu9” |
| Unmodified distribution | Use the project name with accurate version and source information |
| Internal or commercial deployment | Rename the virtual model while retaining attribution in administration or about views |

## ⛔ Prohibited use

- Implying that a modified build, fork, hosted service, or commercial product is officially certified, partnered, or endorsed;
- Using names, visuals, or release pages likely to be confused with the official distribution;
- Removing required license, copyright, NOTICE, or source attribution;
- Injecting `Powered by AI-Tidu9` into every model response in a way that pollutes user content or exposes deployment structure.

## 🏷️ Renaming, white-labeling, and required attribution

Internal and commercial deployments may rename the entry point, virtual model, and interface branding. Keep the following attribution in an administration view, about page, or another reasonably discoverable location:

```text
Powered by AI-Tidu9
```

The attribution identifies technical origin; it does not imply endorsement. It does not need to appear in every generated response, tool call, or final business result.

> [!NOTE]
> The open-source license governs use and distribution of the code. This policy governs names and statements of origin. They serve different purposes.
